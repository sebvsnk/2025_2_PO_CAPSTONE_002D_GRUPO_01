PowerShell

# 1. Crear el entorno virtual (si no existe)
python -m venv .venv

# 2. Activar el entorno
.\.venv\Scripts\Activate.ps1

# 3. Actualizar pip a la última versión
python -m pip install --upgrade pip

# 4. Instalar todas las librerías del archivo requirements.txt
pip install -r requirements.txt

# 5. Iniciar el servidor (opcional, si quieres probarlo de una vez)
python manage.py runserver





Si al ejecutar el paso 2 te sale un error de "scripts deshabilitados", ejecuta este comando una única vez y vuelve a intentar:


Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser


-----------
sirve si se instalan mas librerías y quieres que se guarden en el txt de los requerimientos.
pip freeze > requirements.txt


sirve para desactivar el entorno virtual, útil para reiniciar el entorno
deactivate
