Comprobando /api/v1/health…

Health Check

Endpoint de diagnóstico. Verifica la conexión del backend y la base de datos.

GET /api/v1/health

Bitácora (Portería)

GET lista entradas/salidas (filtros). POST registra nueva ENTRADA o SALIDA.

GET/POST /api/v1/bitacora

OT: Crear y Listar

GET lista OTs (con filtros). POST crea una nueva Orden de Trabajo (OT) activa. Requiere Supervisor/Admin.

GET/POST /api/v1/ot

OT: Detalle y Editar

GET detalle. PATCH/PUT actualiza la descripción de la OT. Requiere Supervisor/Admin.

GET/PATCH /api/v1/ot/<id>

OT: Cambiar Estado

Cambia el estado de la OT (ej: CERRADA). Requiere JSON: {"estado_code": "..."}.

POST /api/v1/ot/<id>/cambiar_estado

Tarea: Crear y Listar

GET lista tareas de una OT. POST crea una Tarea con responsable. Requiere Mecánico/Supervisor.

GET/POST /api/v1/ot/<ot_id>/tareas

Tarea: Ciclo de Vida

Mueve la Tarea entre estados: iniciar, pausar (requiere motivo), reanudar, cerrar. Requiere Mecánico/Supervisor.

POST /api/v1/tareas/<id>/<accion>

Tarea: Repuestos Usados

GET lista repuestos asignados. POST asigna un repuesto (ej: aceite, filtro) con cantidad. ¡Funcionalidad validada!

GET/POST /api/v1/tareas/<id>/repuestos

Tarea: Subir Evidencia

GET lista archivos. POST sube un archivo (foto/pdf) usando multipart/form-data (campo file).

GET/POST /api/v1/tareas/<id>/evidencia

Reporte Horas-Hombre

Métricas de tiempo efectivo por responsable (excluye pausas). Soporta exportación a CSV, XLSX y PDF.

GET /api/v1/reportes/horas-hombre

Reporte Duración Etapa

Mide la duración promedio (incluyendo pausas) por fase del proceso. Filtro: ?patente=... o ?responsable_id=...

GET /api/v1/reportes/duracion-etapa

Reporte de Salidas

Reporte agregado de entradas vs. salidas de vehículos. Filtro: ?period=day|week|month

GET /api/v1/reportes/salidas

Auditoría (Trazabilidad)

GET consulta el historial de todos los cambios críticos (Cierre, Edición, Creación). Solo rol Admin.

GET /api/v1/auditoria

Admin: Gestión de Usuarios

GET lista usuarios. POST invita/crea un nuevo usuario. PUT/DELETE modifica/desactiva. Solo rol Admin.

GET/POST /api/v1/admin/usuarios

Tablero Kanban (Tiempo Real)

Datos de todas las OTs activas/pausadas, agrupadas por estado para la vista de Supervisor/Analista.

GET /api/v1/tablero

Estado Público (Chofer/Cliente)

Consulta pública sin token del estado activo de una OT. Patente normalizada (ej: AB1234).

GET /api/v1/public/status/<patente>

Vehículos (Lista)

Lista todos los vehículos. Permite búsqueda por patente: ?search=AB1234

GET /api/v1/vehiculos

Detalle de Vehículo

Obtiene los datos de un vehículo específico usando su ID (ej. 1, 2, 3). Requiere Autenticación.

GET /api/v1/vehiculos/<id>
